# hd-project19 — 강체 6DOF 마운트 진동 / 공진 해석

4개 마운트의 위치·강성과 강체의 질량·무게중심·관성모멘트를 입력하면 6개 고유진동수와 모드 결합(coupling)을 계산합니다.

- **원 해석 로직**: 김완호(HD건설기계) 님이 만든 [anakizz/6DOF-vibration](https://github.com/anakizz/6DOF-vibration)을 그대로 가져왔습니다. Jacobi 고유값 분해·Cholesky 분해 등 계산 부분은 손대지 않았습니다.
- **이 리포에서 새로 얹은 것**(김완호 님 요청, 2026-08):
  1. **결과 서버 저장** — CSV 내보내기와 별개로 해석 조건·결과를 Supabase에 저장해 다른 기기에서도 불러올 수 있습니다. 로그인 없이 브라우저별 익명 식별자로 "내 기록"을 구분합니다.
  2. **결과 해설(참고용·규칙 기반)** — 계산된 고유진동수 대역을 엔진 회전수·인체 민감대역 등과 단순 비교해 설명을 붙입니다. 실제 대화형 AI 챗봇은 API 키 협의 후 다음 단계로 미뤄뒀습니다(버튼은 준비중 상태로 자리만 있음).

## 로컬 개발

정적 사이트라 빌드 단계가 없습니다. `index.html`을 열면 바로 동작합니다.

```
node test/logic.test.js      # 결과 해설 로직 단위 테스트
node test/smoke.browser.js   # 화면 연기 테스트 (playwright 필요)
```

## 서버 저장을 켜려면

`supabase/schema.sql`을 Supabase SQL Editor에서 실행해야 저장/불러오기가 동작합니다. 실행 전에는 저장 버튼을 눌러도 "저장 기능은 곧 활성화됩니다" 안내만 뜨고 화면은 정상 동작합니다.
