강체 6자유도 마운트 진동 / 공진 해석

4개 마운트의 위치·강성 + 강체 질량·무게중심·관성모멘트를 입력하여 6DOF 고유진동수와 모드 결합을 계산합니다.

1. 강체 입력

무게중심 CG [mm]

관성모멘트 [kg·m²]

관성곱 [kg·m²]

관성행렬은 [Ixx -Ixy -Ixz; -Ixy Iyy -Iyz; -Ixz -Iyz Izz] 형태의 물리적 관성행렬을 사용합니다.

2. 마운트 입력

좌표는 CG 기준 [mm], 강성은 각 방향 [N/mm]입니다. 해석 내부에서는 각각 m, N/m로 자동 변환합니다. 회전은 작은 변위 선형화(roll=x, pitch=y, yaw=z) 기준입니다.
MountX [mm]Y [mm]Z [mm]Kx [N/mm]Ky [N/mm]Kz [N/mm]

3. CSV 입력 / 출력

CSV는 TYPE,NAME,X,Y,Z,KX,KY,KZ,VALUE 형식을 지원합니다. 아래 템플릿을 다운로드하여 수정한 후 업로드할 수 있습니다.
CSV 단위: CGX/CGY/CGZ 및 마운트 X/Y/Z = mm, KX/KY/KZ = N/mm. 관성모멘트/관성곱은 kg·m²입니다.

4. 결과 저장 (서버)

CSV 내보내기와 별개로, 이번 해석 조건과 결과를 서버(Supabase)에 저장해 나중에 다른 기기에서도 불러올 수 있습니다. 이 브라우저에서 저장한 기록만 "내 기록 불러오기"에 나타납니다(로컬에 저장된 익명 식별자 기준).

5. 결과 해설 (참고용 · 규칙 기반)

아래는 계산된 고유진동수 대역을 통상적인 건설기계 가진원(엔진 회전수, 노면·주행 진동, 인체 민감대역)과 단순 비교한 참고용 자동 해설입니다. 실제 설계 판단의 근거로 쓰지 말고, 상세 검토가 필요한 모드를 먼저 짚어보는 용도로만 사용하세요.
먼저 「2. 공진 해석」을 실행하세요.

공진 주파수별 3D 모드 애니메이션

Iso View에서만 적용됩니다. X/Y/Z 슬라이더로 카메라 시점을 회전하며, 진동 모드의 roll/pitch/yaw 회전과는 독립적으로 동작합니다.
강체는 3가지 기본 도형만 사용해 단순화합니다: 엔진 본체(Block + Cylinder Head)=직육면체, Oil Pan=사다리꼴 프리즘, FWH=원통(+X 방향, 엔진 본체 오른쪽 부착). 정면(YZ), 측면(XZ), Top(XY), Iso View를 선택할 수 있으며, Iso View에서는 X/Y/Z축 시점 회전이 가능합니다.

모드 형상 / 주파수 그래프

각 막대는 정규화된 6DOF 모드 형상 성분입니다. DOF 순서는 x, y, z, roll, pitch, yaw입니다.

Mode Coupling Matrix

Coupling %는 각 고유모드의 정규화된 6DOF 벡터 간 겹침 정도를 표시합니다. 대각선은 100%이며, 비대각 성분은 모드 간 형상 유사도를 의미합니다.
